เปิดรอบอบรม

ตั้งค่ารอบอบรม วันอบรม และคำถามในฟอร์ม แล้วส่งลิงก์ให้ผู้สมัครได้ทันที ไม่ต้องสร้างฟอร์มและไฟล์ใหม่ทุกครั้ง

เปิดรับสมัครแล้ว ลิงก์พร้อมส่งให้ผู้สมัคร

รอบอบรม

เลือกหลักสูตรที่มีอยู่ แล้วตั้งชื่อรอบ สถานที่ และจำนวนที่รับ

วันอบรม

บางหลักสูตรมี 1 วัน บางหลักสูตรมี 3 วัน ผู้สมัครลงทะเบียนครั้งเดียวทั้งรอบ ระบบเก็บเช็คชื่อรายวันได้ในระยะถัดไป

จำนวนวันอบรม
ต้องการมากกว่า 3 วัน เพิ่มวันได้เอง

การรับสมัคร

กำหนดช่วงเวลา และกติกาที่ทีมงานอยากใช้ หัวข้อที่ติดป้าย “รอยืนยัน” เป็นข้อที่ต้องถาม FamilyLink
