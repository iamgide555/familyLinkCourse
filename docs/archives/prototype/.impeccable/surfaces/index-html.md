# Surface brief: FamilyLink Phase 1 clickable prototype

Mode: Operate. Surfaces: index.html (meeting hub), create-run.html (admin, desktop), register.html (participant, mobile-first), registrations.html (admin, desktop with mobile fallback).
Audience: non-technical NGO staff (Google Forms/Excel users) and caregiver participants. Job: let FamilyLink react to real screens on Friday and confirm fields/rules. Flow: create run, share link, register, see list, export.
Constraints: Thai primary, static HTML/CSS/JS, localStorage ties the three screens together, all data synthetic and labeled, no sensitive health data, PDPA consent visible.
Unresolved: real fields, approval/waitlist, certificate, logo/brand, Excel columns.

## Direction contract

THESIS: The Thai clinic queue ticket (บัตรคิว / ใบนัด). Every registration is a numbered ticket; the product refuses the card-grid SaaS dashboard and Google-Forms stack.
OWN-WORLD: Cool thermal-paper white sheets with perforated notched edges and dashed tear lines on a pale mint-grey waiting-hall ground; near-black green ink; one hospital teal reserved ONLY for pressable actions; queue numerals huge, tabular, Kanit; body TH Sarabun-family (Sarabun), the government form face. Status never by hue alone: drawn glyph + word + line form (solid, dashed, struck). One warm amber only for attention (waitlist, errors).
STORY: Staff understand in seconds that opening a course yields a link, each sign-up yields a numbered ticket, and the list is their queue. Caregiver sees a calm form, then holds a ticket with queue number. Staff leave Friday with edits, not confusion.
FIRST VIEWPORT: Hub: left a tall ticket stub reading the flow with the next action in teal; right the three screen links as ticket rows. Registration (390px): course ticket header with seats left in large numerals, form below. Admin list: queue-number column dominant, run summary strip with seat ticks, filter chips, search, Export and walk-in actions top right.
FORM: Position 1 of my list (hospital queue ticket, my pick); seed fd4d00fc re-roll 1; user chose pick card; raises: boarding-pass segmented stub on success screen, accent used sparingly from monochrome-product.
